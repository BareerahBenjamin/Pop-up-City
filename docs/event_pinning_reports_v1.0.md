## 活动置顶

管理员可在活动详情及后台活动列表置顶／取消置顶，成员不能自行置顶。有效置顶活动在活动列表最前方单独显示，最近置顶在前、相同时按活动时间排序；不重复进入近期或长期分组。置顶遵守现有搜索、类别、个人范围筛选，不改变日历时间顺序。

仅已发布、未结束活动可新置顶；结束、取消或删除后不在置顶区显示。独立网页表 `website_event_pins` 保存元数据，置顶／取消与操作审计在同一事务完成。新迁移为 `0019_website_event_pins.sql`，不修改原活动、设备表或历史迁移。

## 同一发起人允许时间重叠

创建、编辑、批量预览／导入、审核恢复发布和更换发起人均允许同一用户有重叠时间段的多场活动。保留时间有效性、注册与权限、人数上限及报名绑定要求。批量导入仍拒绝名称、开始时间、地点三者完全一致的重复记录，批次重试仍幂等。
