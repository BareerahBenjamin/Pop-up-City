## 页面范围

全部内容位于原活动页面 `/#events`，不增加页面或侧栏导航。保留原有科技碰瓷节主视觉、概览、搜索筛选、感兴趣安排和活动卡片。按用户反馈移除顶部「活动日历总览／Herstory生活地图／全部活动」跳转栏。

月历和地图沿用既有业务接口。2026-10-19同日新增取消活动隐藏及后台删除功能，涉及0012增量迁移，详见 [活动取消与后台删除](event_deletion_local_v1.0.md)；未修改线上配置。

## 活动日历

- 默认月总览，周日为第一列；月份切换、月份选择器及「今天」均使用景德镇 UTC+8 日期。
- 保留一天／三天／一周时间表；点击日期查看完整当日安排，点击活动进入原详情页。
- 月格最多展示三场，更多活动按钮会定位到当日安排。跨日活动出现在每个实际占用日期，恰好午夜结束不会计入次日。
- 使用现有搜索、类型及个人范围筛选；活动卡片按开始时间从早到晚排列，同一开始时间按结束时间、活动ID保持稳定顺序；日历不显示待审核草稿及已取消活动；已取消活动保留在后台。
- 当日安排接入原有收藏及登录流程，收藏不等于报名。
- 手机月历在自身容器内横向滚动，完整活动名称可在当日安排查看。

## 园区地图

使用用户提供的原始园区插画，按图添加六个可选地点：迎新点、B 栋入住办理、C 栋居住区、C 栋二层公共活动区、E 栋二层课程教室、cue-D 打车定位点。

- 支持地点分类与地图热点选择；地点详情关联现有活动。按用户反馈移除地图下方「下一站，去哪里？」的重复地点卡片及其他地址提示。
- 支持 100%–250% 缩放、复位、放大后拖动及方向键平移，移动范围限制在图片边界。
- 按用户反馈移除路线叠层、行进动效、热点浮动及动效开关；仅保留静态地图、地点选择和手动缩放拖动。
- 地点匹配只使用明确的楼栋／楼层名称；其他地址保留在活动日历，不猜测地图位置。
- 路线及热点依据插画，不是地理坐标或实时导航。★★★★☆（有明确图片依据，实际通行条件仍以现场指引为准。）

地图不受活动搜索筛选影响，便于始终查找入住、居住与抵达地点；地点中的活动展示完整公开安排。

## 活动类型选择

单活动创建／编辑表单中，管理员使用「社区官方活动／居民发起活动」单选，默认居民发起；编辑时回显原选择。主题分类（学习、聚餐等）仍独立填写。单选继续映射现有 `official` 布尔字段，居民不能自行授予官方标记。


## 近期与长期活动分组

活动发现区优先展示「近期活动」卡片，包含正在进行和未开始、持续不足 3 天的已发布活动，组内仍按开始时间、结束时间、ID 升序。持续 72 小时及以上且尚未结束的活动单独列在后面的「长期活动」，用紧凑列表显示完整起止时间、地点与状态；已开始的长期活动优先，再按结束时间排列，未来的长期活动按开始时间排列。

未发布活动另列「待发布活动」，已结束活动进入默认折叠的「往期活动」，最近结束的排在前面。展开状态在页面重绘时保留。搜索、主题和个人筛选先作用于全部活动，再进行分组；日历优先展示当日定时活动，长期活动集中收起，不改变活动时间、报名规则、数据库或接口。

**信心：★★★★☆。** 3 天阈值是当前展示规则，避免为一次页面调整新增后台配置；待运营使用后可再调整。运行 `npm run preview:dashboard` 可查看包含长期活动与往期活动的内存示例。


## 活动审核入口与日历优先级修正

管理后台默认打开活动审核，活动审核标签排在最前并显示待审核数量；列表待审核项优先，支持仅看待审核和全部活动。管理员的活动页增加审核直达入口，普通成员和访客不显示。审核仍使用既有接口与权限，不改写账号角色或审核状态。

月历先展示选中日期的当日安排，再显示整月网格；同一天开始的活动优先于前一日跨夜活动。持续 72 小时及以上的活动不重复进入每日格子、当日清单或一天／三天／一周的小时格，改为在当前展示范围下方的原生折叠列表中集中展示完整起止时间，默认收起，支持键盘展开并保留页面重绘时的展开状态。日历计数仍保留整月活动总数，定时清单和折叠长期清单分别计数。

**信心：★★★★★。** 修正仅涉及前端展示和入口；后台发布／退回按钮、接口授权及活动原始时间保持不变。
