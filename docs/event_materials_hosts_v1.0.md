## 课件

每场活动详情页底部增加“课件与资料”。发起人及管理员可上传、编辑名称、替换文件或删除课件，活动结束后权限继续有效。已发布活动的课件可公开查看；待审核等非公开活动仅其发起人与管理员可访问。已逻辑删除的活动不再提供课件访问，但保留资料数据。

支持 UTF-8 单文件 HTML／HTM、PPT、PPTX。HTML 支持页内交互预览和下载；PPT／PPTX 提供原文件下载，浏览器不直接渲染 PowerPoint。可以为同一课程分别上传 HTML 在线版和 PPT 下载版。没有接入第三方转换或存储服务，也没有导入真实导师课件。

每份文件不超过 20 MB，每场活动最多 20 份、总计 100 MB。HTML 的图片、字体和样式应内嵌或使用 HTTPS 地址。预览使用独立沙箱，允许课件交互脚本，但不授予网站同源访问、网络 API、表单提交或顶层页面控制权。文件名和标题按文本展示，PowerPoint 只按附件返回。

资料内容与元数据保存在 SQLite 的独立新表，纳入既有数据库备份。新增 `0018_event_materials.sql` 仅创建 `event_materials` 与 `event_material_audit`，不修改已有表或迁移。现有业务库尚未执行新迁移；测试只使用内存及隔离临时文件。

编辑、替换和删除携带版本号，防止旧页面覆盖其他人的更新；操作与课件审计在同一事务内提交，失败时保持原文件。发起人变更及活动删除在写入前重新校验，上传进行中失去管理权限不能落库。

## 修改发起人

管理员可从后台活动审核列表或活动详情页点击“修改发起人”，按昵称／邮箱搜索并选择网站内已注册、未停用的用户。仅导入尚未注册的邀请名单、停用账号及不存在的用户不可选。活动结束后仍可修改。

保存只更新 `events.host_id`、对应更新时间，并写入 `event_audit`；活动内容、状态、报名及签到记录不重写。新发起人继承网站编辑和课件管理权限，原发起人不再拥有管理权限（管理员权限除外）。存在活动时间冲突或原发起人已被其他管理员改变时，返回明确提示，不部分保存。

用户明确确认“就只是更换数据库中的发起人，硬件读取发起人”。现有硬件按原代码读取新的发起人；没有修改硬件查询逻辑、协议、接口、绑定、主持人授权、数据同步或固件，也不自动迁移硬件授权。
