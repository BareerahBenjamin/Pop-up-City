# 官网正式部署

此包包含当前工作区源码快照。源码与解包后测试均为 75/75，通过中文名字位图和 RGB565 发布检查。服务器 Linux 测试由现有部署工具在切换前执行。

## 上传和执行

1. 将 `herstory-formal-upload-20261016.tar` 上传到云服务器 `/tmp`。
2. 在云终端执行：

```bash
mkdir -p /tmp/herstory-formal-20261016
tar -xf /tmp/herstory-formal-upload-20261016.tar -C /tmp/herstory-formal-20261016
sudo bash /tmp/herstory-formal-20261016/deploy-formal.sh
```

如果上传界面显示的保存路径不是 `/tmp`，请修改第二行 tar 命令的文件路径。

脚本只操作此项目：核对源码校验值；检查正式域名配置；缺少设备登记密钥时生成并备份原环境文件；保留既有 SMTP、登录密钥和数据库配置；将源码包放入现有项目上传目录；调用已安装的项目部署工具。工具会安装 Linux 依赖、运行测试、核验迁移并做数据库备份，然后切换项目版本，最后检查 HTTPS。不会修改 Caddy、SSH、账号、系统运行时或其他项目。

成功标志为 `FORMAL_WEBSITE_DEPLOY_OK`。请把终端输出发回当前对话，继续进行真实板子的正式环境绑定、星球下载及签到验证。这个标志仅表示官网基础部署验证通过，不表示完整硬件验收通过。邮件是否可用需实际发送登录邮件验证。

部署工具的操作日志保存在 `/opt/herstory-popup-city/deploy-state/operation-*.log`，只允许管理员读取。出现失败请保留原始输出并联系当前对话，不要手动迁移或恢复数据库。如果工具已经切换成功而后续公网验证失败，先诊断公网响应和服务日志；需要回退时执行：

```bash
sudo /opt/herstory-popup-city/deploy-tools/rollback
```

回退保留数据库和新增表，不删除报名或签到记录。新增设备登记密钥不回滚，原环境配置备份位于项目 deploy-state 目录，勿截图或公开该文件。
