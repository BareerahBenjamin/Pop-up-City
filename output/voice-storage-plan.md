# 板子录音断电保留方案（已批准并实现，尚未烧录）

每块板子保存一条最长5秒的录音；8kHz、单声道、IMA ADPCM4压缩，约20KB。进入音频页读取，重录完成后写入。采用独立128KiB NVS分区，留出新旧两份记录及事务空间。失败时不自动擦除存储；新录音提交完成前，旧录音仍作为已保存记录。

| 区域 | 当前布局 | 拟采用布局 |
|---|---|---|
| 分区表 | 0x8000 | 地址不变，内容更新 |
| 绑定和Wi-Fi NVS | 0x9000，24KB | 不变，不擦除 |
| PHY | 0xf000，4KB | 不变 |
| 应用 | 0x10000，大小0x680000 | 0x10000，大小0x660000 |
| 新录音区 voice_notes | 属于应用末尾空闲范围 | 0x670000，128KiB |
| 个人分区 event_save | 0x690000，大小0x170000 | 地址、大小和原数据不变 |

首次迁移需确认实机当前应用不占用0x670000以上范围，然后写入匹配的新应用和分区表。不得直接烧合并镜像，不得整片擦除。后续仅更新应用时，录音区不在应用写入范围内。回退旧布局固件可能重新覆盖录音区，因此回退也需核对写入范围。

验收：分区非重叠检查；音频格式/校验测试；NVS提交失败测试；实机录音和播放；重启与断电后回放；重新录音中途断电时旧记录恢复；绑定、Wi-Fi和个人数据保留复核。

当前状态：用户已明确批准128KiB布局；代码、固件构建和主机存储/分区保护测试通过，已烧录并校验，绑定/Wi-Fi及个人分区未改变。真实断电恢复和音质等待真机验收。
